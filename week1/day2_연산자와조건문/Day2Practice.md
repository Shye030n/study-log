# 놓친 부분
## 연습문제 1 : 두 수 비교해서 큰 수 출력
(x == y)인 경우에도,
x(15)가 y(15)보다 작습니다.
이렇게 출력됨.

     

## Edge Case (경계 케이스) 를 놓치지 않는 습관 필요 !
처음엔 if(x > y)와 else 만 했는데, 
if(x > y)가 아닌 경우는 모두 해당되기 때문에,
값이 동일해도 else인 x 가 y 보다 작다고 콘솔에 찍힌 거임.

# 비교 연산자 ( &&, ||, ! )
## 실무에서는 어떻게 사용할까?
- 로그인 권한 체크, 폼 유효성 검사 (예: 18세 이상인 사용자가 이용약관을 동의 했는가)
```
boolean canSubmit = isAgeVaild && isTermsAreed && !hasError;
```

# 증감 연산자
- ++a;
: 전위 연산
!) 연산 후, 값 대입
- a++;
: 후위 연산
!) 값 대입 후, 연산

전위 연산과 후위 연산 둘 다, 1씩 증감하는 것은 동일하나,
그 결과값을 언제 돌려주느냐(사용하느냐) 가 다른 것.

+) 변수는 이전 연산 결과가 누적된다.

# 변수
```
public class Day2Practice {
    //클래스 몸통
    //직접 실행 코드 X
    //변수 선언(필드), 메서드 정의만 올 수 있음
    // ex Sysout X

    public static void main(String[] args) {

    }
}
```
1. Field = 멤버 변수
: 클래스 몸통 바로 안, 메서드 밖에 선언된 변수

2. 지역 변수 = Local 변수
: 메서드 안에 선언된 변수. main메서드 안에서 만드는 변수

3. 매개변수 = Parameter
: 메서드를 호출할 때 전달받는 변수 (메서드 오른쪽 (여기))
