1) 핵심 키워드
- SELECT : 보여줄 열(= 세로 = 컬럼)
- FROM
- WHERE : 조건에 맞는 행(= 가로 = 로우)
- ORDER BY
- AND / OR / IN 
- IS NULL
- 실행 순서
- DATE 타입

2) 학습 목표
1. SQL이 어떤 순서로 실행되는 지 설명할 수 있다. (작성 순서 != 실행순서)
2. 조건(WHERE)을 조합해서 원하는 행만 정확히 골라낼 수 있다.
3. NULL이 왜 = 로 비교되지 않는지 이해하고 올바르게 조회할 수 있다.
4. 쿼리를 실행하기 전에 몇 행이 나올 지 예측할 수 있다.

4) 개념
SQL의 작성 순서
- SELECT    이 컬럼을 조회
- FROM      어느 테이블의
- WHERE     무슨 조건의 행을
- ORDER BY  어떻게 정렬한다.

SQL의 실행 순서
- FROM      어느 테이블의
- WHERE     무슨 행을
- SELECT    어떤 컬럼을
- ORDER BY  어떻게 정렬한다
** SELECT 에 컬럼의 별칭을 지정해도, WHERE 먼저 실행되기에, SELECT에서 별칭 사용 불가.

-- AND: 둘 다 만족해야 참, OR: 하나만 만족해도 참
     AND는 OR보다 먼저 계산된다. 예시는 다음과 같다.
     순차적으로 진행되는 것이 아니다. 계산 우선 순위에 따라 계산되기에, 괄호를 사용하여 명확히 해야 한다.
     A OR B AND C => A OR (B AND C)
          (A OR B) AND C 처럼 괄호로 계산 순서를 명시해야 한다.
