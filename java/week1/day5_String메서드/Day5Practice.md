# String
: String은 Immutable 속성으로, 한 번 저장한 문자열은 값이 변경되지 않는 속성을 가졌다. 
때문에, String의 메서드로 String 객체의 값을 변경하고자 하지만, 
1. 실질적으로는 기존 문자열에 메서드를 사용한 것을 새로운 변수에 값을 저장해야만 한다. 
2. 혹은 바로 Sysout(변수.메서드())로 사용해야 한다. 이 경우에는, 콘솔에만 바로 출력하고 값이 필요 없는 경우에 해당한다.
## 그 외 String 메서드()
1. .length() : 문자열 총 길이
```
.length() // → String의 길이(글자 수)를 알려주는 메서드
.length   // → 배열의 크기(요소 개수)를 알려주는 속성
```
2. charAt(i) : 문자열(String)에서 char 단위로 하나씩 꺼냄 (반환 타입은 Char)

## equals vs ==
- equals() 는, 두 객체의 "값/내용/문자열" 이 같은지를 비교하는 메서드.
- == 는, 두 객체가 같은 "객체/메모리 주소"를 참조하는가를 비교하는 메서드.
```
String a = "hi"; //단순하게 "" 안에 작성한 문자열은 StringPool에 저장되는데, 
String b = "hi"; //새로운 객체를 또 생성하지 않음  (b를 생성하기 전에, StringPool에서 같은 문자열이 있는지 확인 후 있으면 그걸 재사용)
String c = new String("hi"); // new String으로 생성한 변수는 새로운 객체를 생성하여 저장
String d = new String("hi"); // c와 d 는 서로 다른 메모리 주소를 참조하기에 ==는 false, equals()는 true가 출력된다.
```

### 배운 것
### : 앞으로 + 연산자를 사용할 때는, **연산 내용을 괄호로 감싸는** 습관을 들여야겠다!!
```
System.out.println("c == d" + (c == d));   //true   => O
System.out.println("c == d" + c == d);     //false  => X
```
생각과 다르게 콘솔에 출력된 이유는,
+ 연산자는, +의 왼쪽부터 순서대로 진행된다. => + 연산자의 우선순위는 왼쪽 코드.
때문에 c == d 를 비교하고 싶었지만, "c == d" + c 와 d 를 비교하여 false로 예상과는 다른 출력이 발생했다.
