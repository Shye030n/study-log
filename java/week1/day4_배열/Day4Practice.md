# 배열 / Array


## 개념 )
- 같은 타입의 데이터드를 순서대로 저장한 변수/객체를 배열(Array)라 하고,
- 배열의 첫 인덱스는 0 부터 시작한다.
- 배열의 순회는 for 반복문으로 하며, 예시는 다음과 같다
```
for (int i =0; i < arr.length; i++) {
    System.out.print(arr[i]);
}
```
- 실무에서,
- 서버에서 MyBatis로 데이터를 가져올 때 List<VO>를 사용하는데, 
- 이 객체는, "같은 타입의 데이터를 순차적으로 저장한다"는 점이 배열과 완전히 동일하다.
- MyBatis로 결과를 처리할 때 배열의 인덱스/순회 감각이 그대로 사용된다.

## 특징 )
- 크기가 고정적이다.
- 배열명.length = 배열의 길이/크기를 알 수 있는 필드/속성(메서드 X. 메서드는 () 있음.)
- 배열의 순회는 for 문으로 i<arr.length 만큼 반복
- 배열을 뒤집을 때는, 인덱스가 reversed[i] = original[original.length - 1 - i]

## 느낀 점)
- 배열 순회에서 초기값 설정 시 한 번 더 생각하기. 무의미한 반복 없도록!
