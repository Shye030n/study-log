#Day 1 - 자료형과 형반환

## 배운 것
### 자동 형변환
- int -> double 은 자동 형변환
- 작은 값 -> 큰 값 이기에, 값 손실 없어서 자동으로 형 변환해줌.

### 강제 형변환
- double -> int 는 강제 형변환
- 큰 값 -> 작은 값으로 변환하는 과정에서, 소수점 뒷자리를 없애버려서 값 손실이 있음. 
- 그래서 자바에서는 형 변환할 때,
바꿀타입 담을변수 = (바꿀타입) 기존변수;
- 이렇게, ()안에 바꿀 타입을 명시하게 함.
- 소수점을 없애지 않고, 반올림하고 싶으면 Math.round() 사용.
